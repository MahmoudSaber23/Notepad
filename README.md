# C# Notepad Application

A simple desktop Notepad application built using C# and Windows Forms (WinForms).

This project was developed as a practical exercise to apply Windows Forms controls, events, properties, and file handling.

## Application Preview

![Notepad Application Screenshot](screenshot.png)

## Features

- New: Create a new text document.
- Open: Open existing text files.
- Save: Save text documents.
- Edit: Cut, Copy, Paste, Delete, Undo, and Redo.
- Select All: Select all document content.
- Date & Time: Insert the current date and time.
- Font: Customize the text font.
- Text Color: Change the text color.
- Word Wrap: Enable or disable automatic line wrapping.
- Character Counter: Display the total number of characters.
- About: Display application information.

## Technologies Used

- C#
- Windows Forms (WinForms)
- .NET
- Visual Studio
